# CTS 285 — Systems Analysis & Design

## Course
Systems Analysis & Design. One continuing project, DataMan, runs through
every module. The project does not reset between modules. Each module uses
the evidence the previous module produced.

## Cohort
Instructor and section: ask your instructor.

## Modules
- Module 0: Getting Started
- Module 1: What is Systems Analysis & Design?
- Module 2: From Evidence to Requirements
- Module 3: From Requirements to Product Work
- Module 4: From Product Work to Build-Ready Design
- Module 5: First Flask Implementation
- Module 6: Product: Sprint 1
- Module 7: Product: Sprint 2
- Module 8: Project: Capstone Planning
