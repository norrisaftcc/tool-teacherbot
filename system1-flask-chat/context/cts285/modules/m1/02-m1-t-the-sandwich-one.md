## Assignment: The Robot Sandwich

Write precise instructions for a perfectly obedient robot with no common sense. This is your first practice with explicit requirements, hidden assumptions, sequence, and a verifiable end state.

Analyst rule

**A computer follows what you specify, not what you intended.** Make assumptions visible, make steps testable, and define what counts as done.

### The situation

You have a robot. It is strong, fast, perfectly obedient, and completely literal. Your job is to write instructions that get the robot to make a sandwich from start to finish.

### Create your Markdown file

In your **CTS-285 repository**, create a file named:

`robot-sandwich.md`

Your file must contain:

1. **A title** using a Markdown heading.
2. **An Assumptions section** that states the starting conditions.
3. **Numbered steps** in the exact order the robot should perform them.
4. **A Done When statement** that makes the end state observable.

Caution

Do not use vague actions such as “open the bread” unless the action is precise enough for someone with no prior knowledge to follow literally.

### Repository workflow

1. Open the CTS-285 repository or Codespace you are using for this course.
2. Create or open `robot-sandwich.md`.
3. Write the four required parts above.
4. Save the file.
5. Commit and sync your work to GitHub.
6. Open the file on GitHub and verify that the Markdown renders correctly.
