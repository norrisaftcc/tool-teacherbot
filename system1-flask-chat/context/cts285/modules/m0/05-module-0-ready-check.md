## Module 0 Ready Check — Find, Edit, Save, and Move On

There is nothing to submit on this page. Use it to identify a tool skill that needs a quick refresh before the project work begins.

### You are ready if you can do these without guessing

- Tell the difference between a file and a folder.
- Recognize common file extensions such as `.md`, `.py`, `.html`, and `.zip`.
- Extract a ZIP file before working with its contents.
- Read a path such as `docs/requirements.md`.
- Open a project folder in VS Code and find a file in Explorer.
- Edit and save a plain-text file.
- Recognize the integrated terminal and Source Control areas.
- Explain the difference between a GitHub repository and a Codespace.
- Explain why save, commit, and sync/push are different actions.

### If one of these is rusty

Return to the matching Module 0 page and practice that one skill. You do not need to repeat material you already know.

Outcome

**Ready does not mean expert.** It means you can work with course files and recover when you lose your place.
