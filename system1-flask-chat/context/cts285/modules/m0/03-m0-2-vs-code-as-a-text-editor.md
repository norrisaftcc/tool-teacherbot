## M0.2 — VS Code as a Text Editor

Visual Studio Code is the main text editor you will see throughout CTS-285. You do not need to master every feature. You need to be comfortable opening the correct folder, editing plain-text files, saving intentionally, and using the terminal when instructions call for it.

### The four areas to recognize

#### Explorer

Shows the files and folders in the workspace you opened.

#### Editor

Displays the file you are reading or changing.

#### Terminal

Runs commands from the current project environment.

#### Source Control

Shows Git changes and supports stage, commit, and sync/push workflows.

### Open the folder, not just the file

When possible, use **File → Open Folder** and open the project or repository folder. VS Code treats the open folder as the workspace, so Explorer, the terminal, source control, and project-relative paths all refer to the same place.

Caution

VS Code is a text editor. Do not treat a source file like a Word document. Formatting comes from the text and syntax you type, not from font, paragraph, or page-layout controls.

### Basic workflow

1. Confirm the correct project folder is open in Explorer.
2. Open the file you intend to change.
3. Edit the text.
4. Save the file.
5. Review the file name and folder location before closing it.
6. If the project uses Git, review the changed file in Source Control before committing.

### Useful resource

The official VS Code getting-started guide covers opening folders, the Explorer, editor, terminal, and source control. [Open the Visual Studio Code getting-started guide](https://code.visualstudio.com/docs/getstarted/overview).

Outcome

Open a project folder in VS Code, locate a file in Explorer, edit and save it, and recognize where the terminal and source-control tools are located.
