## Module 0 Overview — Ready to Work

CTS-285 assumes you have used files, folders, a text editor, GitHub, and browser-based development tools before. This short module is a refresher so those tools do not become the hard part of the course.

Analyst rule

**You do not need to memorize every button.** You do need to know where your files are, what you changed, and how to save work without losing it.

### What this module reviews

#### Files and folders

Find, name, move, organize, zip, and unzip project files.

#### VS Code

Use the Explorer, editor, tabs, save commands, and integrated terminal without treating VS Code like a word processor.

#### GitHub Codespaces

Open a repository in a browser-based development environment, edit files, use the terminal, and preserve work in GitHub.

#### Ready-to-work habits

Recognize file extensions, verify the folder you are working in, save intentionally, and check your work before moving on.

### What this module is not

This is not a graded technology unit and it is not a replacement for earlier programming coursework. Use the pages you need. If a skill is already comfortable, skim it and move on.

Outcome

Enter Module 1 able to locate, edit, organize, save, and recover the files you will use throughout CTS-285.

**Start with:** M0.1 — Files, Folders, and ZIP Files.
