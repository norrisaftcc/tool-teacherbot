## Backlog Triage Decision Record

Submit the decision record generated by the Backlog Triage simulation. Your record should show the decisions you made, what changed when new information arrived, and how you responded to the new constraints.

Your artifact

**What to submit.** After completing **M3.4 — Backlog Triage: What Moves Forward?**, generate your decision record and save it in your CTS-285 GitHub repository at:

`docs/decisions/m3-backlog-triage-record.md`

### Submission steps

1. Complete the full Backlog Triage simulation.
2. Generate the M3 Backlog Triage Decision Record at the end of the simulation.
3. Copy the generated Markdown into `docs/decisions/m3-backlog-triage-record.md`.
4. Commit the file to your CTS-285 GitHub repository.
5. Open the rendered file in GitHub and confirm that it is readable.
6. Submit the direct GitHub URL to that file in Canvas.

Caution

**Do not rewrite the simulation.** Submit the decision record produced from your completed simulation. You do not need to write an additional reflection or essay for this assignment.

How this is graded

**What will be graded.** The instructor looks for defensible product decisions, a meaningful response to the new information, and a complete professional decision record. You are not graded on matching one hidden perfect path — there is no single correct set of triage decisions.

How this is graded

**Assignment details.**

- **Points:** 10
- **Submission type:** Website URL — a direct GitHub link to `docs/decisions/m3-backlog-triage-record.md`
- **Graded by:** a three-criterion rubric (product decision reasoning, response to new information, professional decision record)
